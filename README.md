# Curry & Burger

A premium, high-performance fusion dining platform built for the modern culinary experience. Curry & Burger combines the rich flavors of traditional curry with the bold satisfaction of gourmet burgers, delivered through a seamless, native-feeling digital interface.

## Introduction
Curry & Burger is a full-stack web and mobile application designed to provide a "Taste the Fusion!" experience. Whether browsing the menu on a desktop or ordering via the native iOS/Android apps, users enjoy a consistent, fluid, and visually stunning interface optimized for speed and conversion.

## Core Features
- **Gourmet Menu Explorer**: An interactive, category-driven menu system with real-time availability.
- **Unified Cart System**: A persistent, floating cart experience that follows the user across the platform.
- **Native Authentication**: Full support for Native Apple Sign-In and Google Auth, ensuring secure and friction-less entry.
- **Order Tracking**: Real-time visualization of order progress from kitchen to delivery.
- **Smart Deals & Promotions**: Dynamic promotional banners and targeted hot deals to maximize value.
- **Branch Locator**: Integrated geolocation services to find the nearest physical restaurant.
- **Admin Command Center**: A comprehensive management suite for handling orders, menu items, and promotions.

## Key Features
- **Edge-to-Edge Design**: Optimized for modern mobile hardware, including full support for Dynamic Island and notched displays.
- **Glassmorphic UI**: Premium aesthetics using modern design tokens, smooth gradients, and micro-animations.
- **Native Performance**: Built using Capacitor to provide a high-performance, native app experience on iOS and Android.
- **Real-time Synchronization**: Powered by Firebase for instant updates across all user sessions.
- **Secure Payments**: Integrated with Stripe for reliable and secure checkout flows.

## Technologies Used
- **Frontend**: Next.js 15+, React 19, TypeScript
- **Styling**: Tailwind CSS 4, Lucide React
- **Mobile Foundation**: Capacitor 7 (Native iOS & Android integration)
- **Backend/Database**: Firebase (Authentication, Firestore, Cloud Storage)
- **Payments**: Stripe SDK
- **Animation**: Framer Motion
- **State Management**: Zustand
- **Validation**: Zod, React Hook Form
